# Focus Timer

Pomodoro-додаток. Тестове завдання для Pibox · Frontend Engineer.

> Робота в процесі. Повний README — після завершення MVP.

## Запуск

```bash
pnpm install
pnpm dev
```

Відкриється http://localhost:5173.

## Скрипти

| Скрипт | Що робить |
| --- | --- |
| `pnpm dev` | dev-сервер з HMR |
| `pnpm build` | production-build (`dist/`) |
| `pnpm preview` | preview production-build |
| `pnpm typecheck` | TypeScript check без emit |
| `pnpm test` | watch-режим Vitest |
| `pnpm test:run` | one-shot Vitest |
| `pnpm test:ui` | Vitest UI |
| `pnpm lint` | ESLint |

## Стек

React 19 · TypeScript strict · Vite · Zustand · Framer Motion 11 · Lucide React · i18next · Vitest
